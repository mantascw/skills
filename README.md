# skills

Agent skills by [@mantascw](https://github.com/mantascw).

## Install

```bash
npx skills add mantascw/skills
```

Or just the one:

```bash
npx skills add mantascw/skills --skill landing-page
```

Works with Claude Code, Codex, Cursor, OpenCode and [others](https://github.com/vercel-labs/skills#supported-agents).

## Skills

| Skill | What it does |
|---|---|
| [`landing-page`](skills/landing-page) | Builds a landing page through a guided intake — a real brief, references the agent actually opens, and three directions to choose from before any code is written. |
